# SentenceTransformer based on google-bert/bert-base-german-cased

This is a [sentence-transformers](https://www.SBERT.net) model finetuned from [google-bert/bert-base-german-cased](https://huggingface.co/google-bert/bert-base-german-cased). It maps sentences & paragraphs to a 768-dimensional dense vector space and can be used for semantic textual similarity, semantic search, paraphrase mining, text classification, clustering, and more.

## Model Details

### Model Description
- **Model Type:** Sentence Transformer
- **Base model:** [google-bert/bert-base-german-cased](https://huggingface.co/google-bert/bert-base-german-cased) <!-- at revision 0b061b4f7ce140d10dce6b6bd8a77da8ec80931b -->
- **Maximum Sequence Length:** 512 tokens
- **Output Dimensionality:** 768 dimensions
- **Similarity Function:** Cosine Similarity
